How it integrates

Data in: CBS balances, card & UPI spends, deposit/MF holdings, AA-consented external assets.
Advisory engine: deterministic finance math (SIP/goal/allocation) + LLM layer for conversation, with guardrails — advice is always computed, never hallucinated.
Surface: SDK module inside the IDBI mobile app; the avatar runs on-device (SVG + TTS), so it scales to millions at near-zero marginal cost.
Compliance: product suggestions restricted to bank-approved catalogue; full audit log; SEBI IA-aligned suitability checks against the customer's risk profile.

Demo profile is synthetic. In the live prototype the same questions are answered from the customer's real (consented) data. Voice uses the free browser Speech API.
